# 🎮 SimForge — Character Generator

> Create your Sim. Roll the dice. Discover your character.

SimForge é um gerador de personagens inspirado na experiência de criação de Sims. O projeto permite personalizar diferentes características do personagem ou simplesmente deixar o destino decidir e gerar um Sim completamente aleatório. 🎲

## ✨ Funcionalidades

* 🎨 Personalização do tom de pele
* 🧍 Diferentes tipos de corpo
* 👀 Seleção da cor dos olhos
* 💇 Diferentes estilos de cabelo
* 🎨 Personalização da cor do cabelo
* ✨ Traços de personalidade
* 🎲 Geração aleatória de personagens
* 📝 Nomes aleatórios
* 💻 Interface responsiva

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* CSS Animations
* DOM Manipulation

O projeto foi desenvolvido sem frameworks ou bibliotecas externas, utilizando apenas tecnologias fundamentais de desenvolvimento web.

## 🎮 Como usar

1. Abra o SimForge.
2. Escolha as características do seu personagem.
3. Navegue pelas categorias de personalização.
4. Ou clique em **Gerar Sim** para criar um personagem aleatório.
5. Experimente diferentes combinações e crie seu próprio personagem.

## 💡 Sobre o projeto

O SimForge foi desenvolvido como um projeto de front-end com foco em interação, manipulação do DOM e criação de uma interface inspirada em jogos de criação de personagens.

A ideia foi transformar uma aplicação simples em uma experiência visual e interativa, mantendo o projeto leve e totalmente executado no navegador.

## 🚀 Executando localmente

Clone o repositório:

```bash
git clone SEU_REPOSITORIO
```

Entre na pasta:

```bash
cd simforge
```

Abra o `index.html` no navegador ou utilize uma extensão como **Live Server** no VS Code.
